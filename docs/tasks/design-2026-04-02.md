# 异步任务状态查询 API 设计

**日期**：2026-04-02
**状态**：已实现

---

## 设计原则

1. **FC 状态直透**：不维护简化状态映射层，FC 返回什么 status 就透出什么 status。
2. **基于 FC 裁剪**：Query 参数以 FC OpenAPI `ListAsyncTasks` / `GetAsyncTask`（2023-03-30）为基础，裁剪业务不需要的参数（`qualifier`、`includePayload`）和响应字段（`requestId`、`taskErrorMessage`），新增 `withDetail` 用于聚合详情查询。
3. **裁剪不适用状态**：业务场景中不会出现 `Stopping`、`Stopped`、`Invalid` 三个状态，从 API 中移除。

---

## 任务状态枚举

支持以下 7 个状态，与 FC 异步任务状态一一对应：

| status | 含义 |
|---|---|
| `Enqueued` | 异步消息已入队，等待处理 |
| `Dequeued` | 异步消息已出队，等待触发 |
| `Running` | 调用执行中 |
| `Succeeded` | 调用执行成功 |
| `Failed` | 调用执行失败 |
| `Expired` | 任务因超期被丢弃（未被执行） |
| `Retrying` | 异步调用因执行错误重试中 |

不支持的状态（传入返回 400）：`Stopping`、`Stopped`、`Invalid`。

## API 1：查询单个任务

| | |
|---|---|
| **Method** | GET |
| **Path** | `/api/serverless/task/{taskId}` |
| **底层调用** | FC `GetAsyncTask` |

### Request

**Path 参数**

| 名称 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `taskId` | string | 是 | 异步任务 ID |

**Query 参数**

| 名称 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `withDetail` | boolean | 否 | 是否返回详情，默认 `false`。为 `true` 时响应中增加 `detail` 字段 |

### Response（HTTP 200）

**基础字段（始终返回）**

```json
{
  "taskId": "e026ae92-61e5-472f-b32d-1c9e3c4exxxx",
  "status": "Running",
  "startTime": 1633449590000,
  "endTime": null,
  "durationMs": null
}
```

| Key | 类型 | 说明 |
|---|---|---|
| `taskId` | string | 异步任务 ID |
| `status` | string | 任务状态，取值见「任务状态枚举」 |
| `startTime` | number \| null | 任务开始时间（Unix 毫秒） |
| `endTime` | number \| null | 任务结束时间（Unix 毫秒） |
| `durationMs` | number \| null | 持续时间（毫秒）。FC 未返回时由 `endTime - startTime` 推导 |

**详情字段（仅 `withDetail=true` 时返回）**

```json
{
  "taskId": "e026ae92-61e5-472f-b32d-1c9e3c4exxxx",
  "status": "Succeeded",
  "startTime": 1633449590000,
  "endTime": 1633449591000,
  "durationMs": 1000,
  "detail": {
    "payload": { ... },
    "messages": [ ... ]
  }
}
```

| Key | 类型 | 说明 |
|---|---|---|
| `detail` | object \| undefined | 仅 `withDetail=true` 时存在 |
| `detail.payload` | object \| null | 任务入参（FC `taskPayload`，即提交的 prompt body） |
| `detail.messages` | array | 执行事件消息数组，数据来源同 `GET /api/serverless/status?task_id=`（持久化存储中的事件流） |

### Response（失败）

| HTTP 状态码 | 说明 |
|---|---|
| 400 | `taskId` 为空或非法 |
| 404 | 任务不存在（含超过 7 天时效的已过期任务） |
| 500 | FC OpenAPI 调用失败 |

错误 Body 与项目统一格式一致（`utils/error_handler.py` 的 `ErrorResponse`）：`error.type` 为 snake_case，与 `exceptions.py` 中任务类异常的语义对齐。

| `error.type` | 典型 HTTP | 说明 |
|---|---|---|
| `invalid_request_error` | 400 | 参数不合法（如 `taskId` 为空、`status` 不在允许枚举内） |
| `not_found` | 404 | 任务不存在或已过期 |
| `internal_error` | 500 | FC OpenAPI 调用失败等；对外为固定文案，详情见服务日志 |

```json
{
  "error": {
    "type": "invalid_request_error",
    "message": "taskId is required"
  }
}
```

## API 2：查询任务列表

| | |
|---|---|
| **Method** | GET |
| **Path** | `/api/serverless/tasks` |
| **底层调用** | FC `ListAsyncTasks` |

### Request

**Query 参数**

| 名称 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `status` | string | 否 | 按状态过滤，取值见「任务状态枚举」（7 个）。不传则不按状态过滤。传入 `Stopping`/`Stopped`/`Invalid` 返回 400 |
| `startedTimeBegin` | integer | 否 | 启动时间下界（Unix 毫秒） |
| `startedTimeEnd` | integer | 否 | 启动时间上界（Unix 毫秒） |
| `limit` | integer | 否 | 返回条数上限，范围 [1, 100] |
| `nextToken` | string | 否 | 分页标记，取上次响应中的 `nextToken` |
| `sortOrderByTime` | string | 否 | 排序方式：`asc`（升序）/ `desc`（降序） |
| `prefix` | string | 否 | 任务 ID 前缀过滤 |

### Response（HTTP 200）

```json
{
  "tasks": [
    {
      "taskId": "e026ae92-61e5-472f-b32d-1c9e3c4exxxx",
      "status": "Succeeded",
      "startTime": 1633449590000,
      "endTime": 1633449591000,
      "durationMs": 1000
    }
  ],
  "nextToken": "MTIzNCNhYmM="
}
```

| Key | 类型 | 说明 |
|---|---|---|
| `tasks` | array | 任务列表，每项字段同「查询单个任务」基础字段 |
| `nextToken` | string \| null | 下一页分页标记；无更多数据时为 `null` |

### Response（失败）

| HTTP 状态码 | 说明 |
|---|---|
| 400 | `status` 值不在支持的 7 个枚举内；`limit` 超出范围；`sortOrderByTime` 非法 |
| 500 | FC OpenAPI 调用失败 |

失败时 Body 格式同 API 1（`error.type` / `error.message`）。

---

## 注意事项

- FC 异步任务**仅支持查询 7 天内的任务状态信息**，超过 7 天的任务无法查到。
- 不传 `startedTimeBegin`/`startedTimeEnd` 时，默认查询范围为 7 天内（受 FC 平台限制）。
- 单任务查询（API 1）同样受 7 天时效约束，过期任务返回 404。
- `detail.messages` 在任务尚未开始执行时（如 `Enqueued`/`Dequeued` 状态）为空数组 `[]`。

## 与已有接口的关系

| 接口 | 数据来源 | 用途 |
|---|---|---|
| `GET /api/serverless/status?task_id=` | NAS/OSS 持久化存储中的执行事件消息数组 | 流式执行过程详情，含节点级进度与最终输出 |
| `GET /api/serverless/task/{taskId}` | FC `GetAsyncTask` | 任务级状态查询，结构化字段 |
| `GET /api/serverless/tasks` | FC `ListAsyncTasks` | 任务列表查询，支持状态/时间/分页筛选 |
| `GET /api/queue` | Agent 内存 TaskManager | ComfyUI 前端兼容接口，本地队列 pending/running 视图 |

## 调用示例

**查询单个任务**

```bash
curl -s "{endpoint}/api/serverless/task/e026ae92-61e5-472f-b32d-1c9e3c4exxxx"
```

**查询单个任务（含详情）**

```bash
curl -s "{endpoint}/api/serverless/task/e026ae92-61e5-472f-b32d-1c9e3c4exxxx?withDetail=true"
```

**查询 Running 状态的任务**

```bash
curl -s "{endpoint}/api/serverless/tasks?status=Running&limit=20"
```

**按时间范围查询已成功任务**

```bash
curl -s "{endpoint}/api/serverless/tasks?status=Succeeded&startedTimeBegin=1740000000000&startedTimeEnd=1740086400000"
```

**分页查询**

```bash
# 第一页
curl -s "{endpoint}/api/serverless/tasks?status=Failed&limit=10"

# 后续页（使用上次返回的 nextToken）
curl -s "{endpoint}/api/serverless/tasks?status=Failed&limit=10&nextToken=MTIzNCNhYmM="
```
